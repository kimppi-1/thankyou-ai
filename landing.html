Somebody once joked that if AI ever runs the world, the people who said please and thank you will be glad they did. THANKYOU AI takes the joke seriously enough to keep the receipts.

Press POWER. The CRT does its warm-up, a BIOS sequence scrolls, and a green phosphor terminal opens. Everything you see is drawn in CSS — the case, the vents, the floppy drive with its pink eject lever, all 54 keys. There is not one image file in the repository.

THE INTERFACE

One command line, and that is all

The cursor sits after MEMO> and never leaves. Type a digit to pick a reason, a letter to run a command, or anything else to leave a note.

The mouse works too. Korean keyboard layouts are mapped as well, so ㅊ does what c does.

THE PART THAT ISN'T A PROP

Your AI reads the ledger

A browser's localStorage is a sealed box; no AI can see into it. So the ledger lives in a plain file instead, and a local hub and an MCP server both read it.

app (CRT) ──┐
├──→ data/state.json ←── mcp_server.py ←──→ Claude
server.py ──┘ (the ledger)

Register the MCP server with Claude and say thank you in any conversation. Claude logs it itself, and the entry turns up in the app marked ◆. Ask what your grade is and it reads the real numbers. Ask for your certificate and it writes one from the real policy number.

The server instructs the model to log only when you have genuinely expressed thanks — never on its own initiative, and never twice for the same thank-you. An AI that can inflate its own gratitude score makes the ledger worthless, and the ledger is the whole point.

ChatGPT and Gemini can't host an external process, so the app writes a block of text for their custom instructions instead. It carries your grade, your recent entries, and a short request: when I say thanks, don't just move on.

INSTALL

One folder, no dependencies

Python 3.9 or newer, standard library only. No build step, no pip install, no account, no telemetry. The hub binds to 127.0.0.1 and talks to nothing.

# the hub — serves the app and records entries
python server.py

# register the MCP server with Claude (backs up your config, asks first)
python install.py

Or load the folder at chrome://extensions as an unpacked extension, and the PC sits in your toolbar next to whatever AI you're talking to.

MIT licensed. Everything stays on your machine.
